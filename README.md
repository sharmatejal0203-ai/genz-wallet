# VELORA 💳

### Smart money, made simple.

VELORA is a personal finance prototype designed to help young users understand their spending, build saving habits, and make smarter everyday money decisions.

## ✨ Features

- 💰 Demo wallet balance
- ➕ Add money
- ↗ Send money
- ⇄ Request money
- 💳 Virtual demo card
- 🔒 Freeze / unfreeze card
- 🎯 Custom savings goals
- 📊 Spending trends
- 📈 Category-based spending
- 🧠 VELORA Money Score
- 🔥 Saving streak
- 🔔 Notifications
- 🔎 Transaction search
- 👤 Profile and monthly budget

## 🎯 Why VELORA?

Managing money can feel complicated when you're just starting.

VELORA turns everyday money activity into simple visual feedback so users can understand:

**Track → Understand → Save → Improve**

## 🛠 Built With

- Python
- Streamlit
- Pandas

## 🚀 Demo

VELORA is currently a prototype.

It does not connect to real bank accounts or process real payments.
